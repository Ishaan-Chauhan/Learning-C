# 💻 C Projects & Simulations

A collection of C programming projects, interactive terminal games, graphics simulations, and core utility applications.

---

## 📂 Project Index

### 🎮 Games & Interactive Applications
* **`TICTACTOE.C`** — Interactive Tic-Tac-Toe game for the terminal.
* **`Bank_Simulator.C`** — Banking system simulation handling basic account operations.
* **`Calculator.C`** — Basic calculator application.

### 🧪 Physics & Graphics Simulations
* **`laser_simulation.c`** — Physics simulation project on laser dynamics using Turbo C graphics.
* **`TRAINGLE.C`** — Multi-triangle pattern generator featuring modern terminal colors.

### 📊 Management Systems & Utilities
* **`student_db.c`** — Student Record Management System for storing and managing student data.
* **`INVENTORY.C`** — Inventory management application.
* **`LIBRARY.C`** — Library management system program.

### 🧱 Data Structures & Math Operations
* **`LINKEDLIST.C`** — Implementation and demonstration of Linked List data structures.
* **`MATRIX.C`** — Program for matrix operations and linear algebra routines.
* **`IITBTASK.C`** — Multi-function menu application.
