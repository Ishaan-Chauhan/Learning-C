# 🚀 Learning-C: Practice Directory

Welcome to my C language practice repository! This folder (`09 - Practice`) contains various programs, mini-projects, and algorithmic exercises developed while learning and mastering C.

---

## 📂 File Index & Descriptions

### Arrays & Matrices
* **`2D_1D.c`** — 2D Array converted into 1D Array
* **`MultiLevelProgram.c`** — 1D array and 2D array options menu
* **`TASKARRA.C`** — Menu-driven 1D array and 2D matrix engine

### Recursion & Math Applications
* **`FactorNo.c`** — Finding factors using recursion
* **`PrimeNo.c`** — Finding Prime numbers using recursion
* **`TablePrint.c`** — Mathematical tables using recursion
* **`Numb_Multi.c`** — Interactive math menu application
* **`RANDOM.C`** — Basic arithmetic operations

### Geometry & Logic
* **`p1.c`** — Check if angles form a triangle or not
* **`p2.c`** — Quadrant Finder
* **`p4.c`** — Quadrilateral shape and area calculator program
* **`p5.c`** — Finding perfect numbers in a given range
* **`p7.c`** — Odd or Even number checker
* **`p8.c`** — Palindrome number checker
* **`MOR239.C`** — Triangle generation by user input

### Binary & Bitwise Operations
* **`pNo_biary.c`** — Binary number conversion practice
* **`pRange_binary.c`** — Range of numbers converted into binary
* **`pswap_binary.c`** — Number to binary conversion

### Data Structures & Systems
* **`Student.c`** — Script for CRUD operations on student records
* **`Array_Choice.c`** / **`Array_prime.c`** — Array-based logical exercises

### Testing & General Practice
* **`TESTING.C`** — Increment/Decrement operator evaluation
* **`p10.c`**, **`p6.c`** — General coding practice exercises

## ⚙️ How to Compile and Run

You can compile and run any of these `.c` files using a standard C compiler like `gcc`. Open your terminal in the directory and run:

```bash
# Compile a specific file (e.g., Student.c)
gcc Student.c -o student

# Run the executable
./student
